# Eight-week synthetic-versus-real market ML project
Start with EIGHT_WEEK_PROGRAMME.md. Each week folder contains Python and/or R modules.
These are educational, inspectable starter modules, not a drop-in replacement for your existing price_modeling.py, market_analysis.py, analyze_looped_results.R or ml_model.py.
Dependencies: pandas numpy scikit-learn; R: readr dplyr ggplot2 TTR.
Use historical data with documented permission. No API credentials or market data are bundled.
The 0–1 score is an explicit normalized similarity, not an accuracy probability.
Run each module with your own validated CSV; build the orchestration CLI during the programme.
